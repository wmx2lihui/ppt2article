# Stage 01: Input Processing Pipeline

## Goal
Convert raw research materials into structured scientific information.

## Inputs
- PPT/PPTX
- PDF papers
- figures
- supplementary materials
- author notes

## Operations
1. Extract slide text
2. Understand figures
3. Recover equations and algorithms
4. Build research memory
5. Identify missing information

## Output
research_memory.yaml

The output is consumed by all downstream agents.
