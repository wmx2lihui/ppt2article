# Output Package Specification

The final generated project should be directly usable for journal submission.

```
submission_package/
├── manuscript/
│   ├── main.tex
│   ├── reference.bib
│   ├── sections/
│   └── figures/
├── supplementary/
├── cover_letter/
├── highlights/
├── graphical_abstract/
└── reviewer_response/
```

Quality gate:

- LaTeX compilation passed
- All citations resolved
- All figures referenced
- Reviewer simulation completed
