# Concept Linking

## Goal

Connect concepts across papers and domains.

## Linking Types

### Scientific Concept

Example:

```
reactive transport
 -> multiphysics coupling
 -> nonlinear solver
```

### Method Evolution

```
traditional method
 -> improved method
 -> current state-of-the-art
```

### Evidence Linking

```
claim
 -> experiment
 -> reference
```

## Application

Used by agents to generate stronger introductions and related work sections.
