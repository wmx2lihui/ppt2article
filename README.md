# ppt2article

## AI-driven Scientific Paper Reconstruction System

`ppt2article` aims to transform scientific presentation materials into complete LaTeX manuscript projects through a multi-agent workflow.

## Vision

Input:
- PPT/PDF research presentations
- Existing figures
- Experimental results
- Research notes

Output:
- Journal-ready LaTeX manuscript
- BibTeX references
- Figures and tables
- Cover letter
- Highlights
- Reviewer response package

## Core Pipeline

```
PPT
 ↓
Scientific Understanding
 ↓
Research Knowledge Graph
 ↓
Paper Architecture
 ↓
LaTeX Generation
 ↓
Citation Integration
 ↓
Reviewer Simulation
 ↓
Revision
 ↓
Submission Package
```
