# Agent Roles

## 1. Scientific Understanding Agent

Purpose:
Recover the scientific logic hidden in PPT slides.

Responsibilities:
- Extract research questions
- Identify methodology
- Build knowledge graph
- Detect assumptions

---

## 2. Contribution Analysis Agent

Purpose:
Find publishable novelty.

Responsibilities:
- Compare with existing literature
- Rank contributions
- Suggest stronger scientific positioning

---

## 3. Journal Strategy Agent

Purpose:
Adapt manuscript to target journals.

Responsibilities:
- Journal selection
- Formatting requirements
- Storyline optimization

---

## 4. LaTeX Generation Agent

Purpose:
Generate a compilable manuscript.

Responsibilities:
- Section files
- Equations
- Figures
- Tables
- References

---

## 5. Reviewer Simulation Agent

Purpose:
Predict peer review problems.

Responsibilities:
- Generate reviewer comments
- Identify missing experiments
- Recommend revisions

---

## 6. Revision Agent

Purpose:
Produce final submission version.

Responsibilities:
- Address comments
- Improve clarity
- Prepare response letter
