# ppt2article v0.3 Architecture

## Goal

Build a complete AI scientific paper reconstruction system.

Input:
- Research PPT
- PDF slides
- Experimental figures
- Notes

Output:
- Journal-ready LaTeX project
- Figures
- Tables
- BibTeX references
- Submission materials

## Core Pipeline

PPT Mining
→ Scientific Memory
→ Paper Planning
→ Manuscript Generation
→ LaTeX Assembly
→ Reviewer Simulation
→ Revision
→ Submission Package

## Design Principle

The system should not generate text directly from slides. It must first reconstruct the scientific logic behind the research.
