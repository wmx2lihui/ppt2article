# FIGURE_PIPELINE

## Purpose

Convert PPT figures into publication-quality scientific graphics.

## Workflow

PPT figure

↓

Figure Understanding Agent

↓

Scientific role identification

↓

Refinement

↓

Vector PDF/SVG output

↓

LaTeX integration

## Quality Requirements

- Vector format whenever possible
- Consistent typography
- Clear labels
- Journal-compatible style
- Caption generated from scientific meaning

## Figure Metadata

```yaml
figure:
  name:
  role:
  section:
  message:
  caption:
```
