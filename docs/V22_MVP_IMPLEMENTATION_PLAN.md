# ppt2article v2.2 MVP Implementation Plan

## Goal
Build the first executable pipeline:

PPTX/PDF -> Research Memory -> Draft Manuscript -> LaTeX Package -> PDF

## MVP Scope

### Phase 1 Input
- PPTX parsing
- PDF parsing
- Image extraction
- Metadata collection

### Phase 2 Understanding
- Slide structure extraction
- Scientific concept extraction
- Figure semantic analysis
- Research memory JSON generation

### Phase 3 Generation
- Paper outline generation
- Section drafting
- BibTeX placeholder generation
- LaTeX project creation

### Phase 4 Validation
- LaTeX compile check
- Missing reference detection
- Figure path validation

## Non-goals
- Fully autonomous scientific discovery
- Automatic acceptance prediction
- Replacement of expert review

The MVP focuses on a reliable PPT-to-paper engineering pipeline.
