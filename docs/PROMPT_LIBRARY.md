# PROMPT_LIBRARY

## Purpose

Store reusable prompts for ChatGPT Plus execution.

## Prompt Categories

```
01_ppt_understanding
02_contribution_analysis
03_paper_structure
04_latex_generation
05_reference_search
06_reviewer_simulation
07_revision
```

## Prompt Design Principle

Every prompt should specify:

- Role
- Input
- Task
- Constraints
- Output format
- Quality criteria

The prompt library is the operational layer connecting human researchers and AI agents.
