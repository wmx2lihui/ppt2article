# REVIEW_PROTOCOL

## Objective

Simulate peer review before submission.

## Reviewer Roles

### Reviewer 1: Scientific Expert

Checks:
- novelty
- theoretical correctness
- assumptions

### Reviewer 2: Method Expert

Checks:
- algorithm
- experiments
- reproducibility

### Reviewer 3: Journal Editor

Checks:
- significance
- story quality
- journal fit

## Output Format

```
Major concerns
Minor concerns
Required revisions
Acceptance probability
```

Revision Agent converts comments into actionable manuscript changes.
