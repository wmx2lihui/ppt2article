# CITATION_ENGINE

## Goal

Build a reliable academic citation system.

## Responsibilities

- Identify required background references.
- Find seminal and recent papers.
- Generate BibTeX records.
- Check citation consistency.

## Citation Mapping

Each citation should answer:

1. Why is this paper cited?
2. Which statement does it support?
3. Is the source authoritative?

## Output

```
reference.bib
citation_map.yaml
```

The citation agent should avoid meaningless citation accumulation and prioritize relevance over quantity.
