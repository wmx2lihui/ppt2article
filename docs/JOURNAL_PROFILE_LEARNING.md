# Journal Preference Learning Protocol

## Goal

Learn the publication logic of a target journal instead of imitating individual papers.

## Input

- Recent representative papers
- Author guidelines
- Scope description
- Editorial statements

## Extract

- preferred scientific questions
- innovation patterns
- manuscript organization
- introduction logic
- result presentation style
- figure expectations
- common rejection reasons

## Output

journal_profile.yaml

The profile guides story design, writing style, and quality control.
