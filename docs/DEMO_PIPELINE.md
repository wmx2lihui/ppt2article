# End-to-End Demo Pipeline

## Objective

Validate that PPT2Article can transform a research presentation into a submission-ready LaTeX package.

## Pipeline

1. Import PPT
2. Extract scientific knowledge
3. Build research memory
4. Analyze target journal
5. Learn reference writing style
6. Design paper story
7. Generate LaTeX manuscript
8. Run reviewer simulation
9. Revise manuscript
10. Export submission package

## Success Criteria

- Complete LaTeX project
- Valid bibliography
- Organized figures
- Journal-aligned manuscript
- Reviewer report completed
