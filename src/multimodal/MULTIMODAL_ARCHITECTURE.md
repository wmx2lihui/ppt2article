# v2.7 Multimodal Scientific Intelligence

## Goal

Enable ppt2article to understand scientific materials beyond plain text.

## Supported Modalities

- Figures
- Equations
- Tables
- Algorithm diagrams
- Slide layouts

## Pipeline

Input artifact

↓

Multimodal parser

↓

Scientific semantic representation

↓

Research Memory update

↓

Paper generation

## Design Principle

The system should not only extract visual objects, but infer their scientific role in the manuscript.
