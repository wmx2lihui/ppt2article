# Scientific Validation Design v2.6

## Purpose

Check whether generated manuscripts are scientifically supported.

## Validation Items

### Claim Check

Verify that conclusions are supported by experiments or references.

### Equation Check

Verify notation consistency, units, and assumptions.

### Citation Check

Verify that references support the corresponding claims.

### Reproducibility Check

Verify that methods contain sufficient implementation details.

Workflow:

```
Draft Manuscript
 |
Validation Agents
 |
Risk Report
 |
Revision Loop
```
