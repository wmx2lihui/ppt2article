# v3.0 AI Paper Generation Engine

## Goal

Connect research understanding, journal style transfer, references, validation, and LaTeX generation into a complete manuscript generation pipeline.

## Pipeline

Input:
- Research Memory
- Target Journal Profile
- Reference Paper Style Profile
- Literature Graph

Process:
1. Build paper story
2. Generate section plans
3. Write manuscript sections
4. Insert figures/tables/references
5. Validate scientific consistency
6. Export LaTeX package

## Principles

The engine generates scientific arguments rather than expanding slide text.
