# Reference Intelligence Design v2.8

## Goal
Build an intelligent literature system that understands why a reference is needed instead of simply inserting citations.

## Pipeline

```
Research Claim
      |
      v
Literature Retrieval
      |
      v
Citation Relationship Analysis
      |
      v
Related Work Generation
      |
      v
Citation Consistency Check
```

## Core Objects

- Paper
- Method
- Problem
- Claim
- Evidence
- Citation relationship

## Output

The system should generate:

- reference candidates
- citation rationale
- related work structure
- citation risk report
